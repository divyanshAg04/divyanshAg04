### 🏥 MedCore – Deep Dive

**MedCore** is a production‑grade hospital management platform designed to streamline clinical and administrative workflows. It handles complex data relationships and ensures secure, role‑based access for doctors, patients, and staff.

**Key Modules:**
- 👨‍⚕️ **Patient Management** – Register, update, and view patient histories.
- 📅 **Appointment Scheduling** – Book, reschedule, and cancel appointments with real‑time availability.
- 💳 **Billing & Invoicing** – Generate itemised bills and track payments.
- 💊 **Pharmacy Inventory** – Manage stock levels, track medicine usage, and auto‑alert low supply.
- 📋 **Medical Records** – Securely store and retrieve diagnostic reports, prescriptions, and treatment plans.
- 📊 **Analytics Dashboard** – Visualise key metrics: patient inflow, revenue, appointment trends, and inventory turnover.

**Security & Architecture:**
- 🔐 **RBAC** – Fine‑grained permissions for admin, doctor, receptionist, and pharmacy roles.
- 🛡️ **JWT Authentication** – Stateless, secure session management with middleware‑based route protection.
- 🧩 **Scalable Schemas** – Designed MongoDB models for efficient querying and future growth.

### ⚙️ DevOps Java Application – Overview

This project was my sandbox for mastering the DevOps lifecycle:

- **Continuous Integration:** Automated builds and tests triggered on every push via GitHub webhooks.
- **Continuous Delivery:** Jenkins pipelines that build, test, and deploy the application to staging environments.
- **Containerisation:** Docker images created for consistent runtime behaviour across dev, test, and prod.
- **Orchestration:** Explored Kubernetes pod scheduling, service discovery, and rolling updates.
- **Monitoring & Logging:** Integrated basic health checks and log aggregation to understand system behaviour in production.
